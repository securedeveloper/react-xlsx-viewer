# react-xlsx-viewer

> **Status: planned.** This package is not usable yet. Version 0.0.1 only reserves the name.

Render .xlsx and .csv workbooks in React: styles, merged cells, frozen panes, sheet tabs and formulas. Built on [javascript-excel](https://github.com/securedeveloper/javascript-excel).

The design of the first version, a read-only viewer, is in [docs/api.md](https://github.com/securedeveloper/react-xlsx-viewer/blob/main/docs/api.md) and [docs/ux.md](https://github.com/securedeveloper/react-xlsx-viewer/blob/main/docs/ux.md).
